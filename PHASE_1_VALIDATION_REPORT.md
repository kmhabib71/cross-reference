## ⚠️ Critical Discoveries for Next Phases

### 1. Section 163 Complexity Challenge
**Finding**: Multiple variations require advanced NER
- **Variations**: ধারা ১৬৩, ধারা একশত তেষট্টি, Section 163, s.163
- **Context Sensitivity**: Same reference means different things in different contexts
- **Cross-Document Network**: Found in 7 files with 20+ section relationships

**Phase 1.5 Requirement**: Advanced Bengali Legal NER to handle all variations

### 2. Bengali Numeral Inconsistency
**Finding**: Mixed numeral usage within same documents
- **Pattern**: Same document uses both ১৬৩ and 163
- **Variations**: "ধারা ১৬৩" vs "১৬৩ নং ধারা" vs "একশত তেষট্টি ধারা"
- **Impact**: Basic pattern matching insufficient

**Phase 1.5 Requirement**: Contextual disambiguation system

### 3. Temporal Law Conflicts
**Finding**: 3 financial year versions with different provisions
- **Authority Chain**: Finance Ordinance 2025 > Income Tax Act 2023
- **Version Changes**: Section 163 rates modified between FY 2024-25 and 2025-26
- **Effective Dates**: Complex date-based precedence rules

**Phase 2.5 Requirement**: Temporal law version control system

### 4. Indirect Reference Resolution
**Finding**: Legal texts use indirect references extensively
- **Pattern**: "উক্ত ধারা" (that section), "পূর্বোক্ত বিধান" (aforementioned provision)
- **Challenge**: Requires context understanding for resolution
- **Impact**: 15-20% of references are indirect

**Phase 1.5 Requirement**: Context-aware reference resolution
